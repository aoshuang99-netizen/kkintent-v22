### 裁定 2 — 音效默认关闭「升级为更硬的承诺」
原来默认关但**记住 on**（`sessionStorage`）→ 回来时被噪音迎接，装饰层最糟的失败模式。现在**彻底不持久化**（删 `KEY`/`readPref`/`writePref`），`init()` 恒静音，第一个 `AudioContext` 只在点击里创建；`state()` 暴露 `defaultOn/persisted/gestures` 让承诺**可读**。

### 裁定 3 — 契约成为**数据**（`kk.prediction.v1`）
`PREDICTION_CONTRACT`（12 字段 + 4 `weights` + `cap 0.97` + 5 invariants）、`validatePrediction()` 返回**报告对象**（不是布尔）、`confidenceFromBasis()` 为**唯一评分函数**（`predict()` 与门禁共用 → 数字与理由无法漂移）。
🔴 **`notAModel` 刻意不 pin 成 true**：*"a flag that can only ever hold one value is decoration, not information"* → pin 的是规则。接真模型时**只有两个字段改变含义**：`provider`、`notAModel`。洞本身也是数据 → `modelAdapterContract()` 返回 `NOT_CONNECTED` + `endpoint:null`。

### 裁定 4 — ScrollTrigger 只被**一个页面**加载
`assets/vendor/ScrollTrigger.min.js` 3.12.5（43,380 B，sha256 `ad33c2df9ada8a66…`），本地 vendored 不走 CDN。规则不是"用/不用"，而是**在滚动有意义的地方引入**：两个概念壳是视图路由、无可滚动内容 → 仍不引入。
- 🔴 **`overflow-x: clip` 而非 `hidden`**：`base.css` 给 `body` 设了 `hidden`，Chrome 下会把 body 变成滚动容器 → ScrollTrigger pin 测 `position:fixed` 会测错盒子。
- **无 JS 也有内容写在 CSS 层**：`[data-st="on"] .reveal{opacity:0}` —— 无 ST / 无 JS / reduced motion 时 `data-st` 永不为 `"on"` → 隐藏态永不生效。营销页不该靠"记得处理"避免白屏。
- **pin 的退化设计**：四步是一条 `<ol>`，钉住时刷高亮，未钉住时四步只是可见列表。

### 裁定 5 — `setScenario` 从「清空」改为「**交换**」
store 从两切片变**三切片**：`scenario`（切换时**重建**）/ assembled work（`pipeline`+`cards`+`signals`，按工作区**槽位交换**）/ account（**永不动**）。头注释立场：*"a workspace switch is a change of context, not a `git reset`"*。`assembledAt` 是**图的身份**：只写一次、永不覆盖，后续追加只更新 `lastAssembledAt`（门禁跨切换比对它）。

**排查中连带修掉 3 个真缺陷 + 1 个跨概念形状不一致：**
1. `setNodeState()` 未 `stash()` → 节点状态只靠对象别名生效，**reload（JSON parse 出独立副本）后静默失效**。修：每次节点状态写入都 stash，且 `load()` 末尾把槽位**重新指向活对象**。
2. `concept-compile.nextState()` **替换**而非合并管线记录 → 丢掉 `assembledAt/builtAt/fingerprint/cards`，即**"跑一个节点就把图变成未装配"**。修：`Object.assign({}, prev, {...})`。
3. `markAssembled()` 每次都覆盖 `assembledAt` → 首次装配时间戳失去意义（恰是保留性断言要比对的字段）。修：首次装配只写一次。
4. **N 把 `signals` 写成裸对象而 S 用数组** → 两页共用同一 `sessionStorage` key，只在同 tab 重载时才暴露。修：N 改数组。
